# 민방위 대피시설 안전도 머신러닝 분석 및 시각화

이 프로젝트는 서울시 민방위 대피시설 데이터를 기반으로, 특정 위치의 실질적인 대피 혜택 여부(안전도)를 머신러닝으로 예측하고 사각지대를 시각화하는 파이썬 기반의 프로젝트입니다.

단순한 거리 기반의 측정을 넘어서, **각 대피소의 최대 수용 인원에 비례하는 동적 커버리지 반경**을 적용하여 훨씬 더 현실적이고 정확한 대피 접근성 지표를 산출합니다.

## 📊 데이터 출처
본 프로젝트에 사용된 '민방위 대피시설' 원본 데이터는 **[서울 열린데이터 광장](https://data.seoul.go.kr/)**에서 제공하는 공공데이터를 바탕으로 하고 있습니다.

## 🗂 파일 구조 및 설명
- `민방위대피시설_서울특별시.csv` : (원본 데이터셋) 서울시 대피소 공공데이터 (cp949 인코딩)
- `convert_encoding.py` : 원본 데이터의 인코딩을 UTF-8로 변환하여 `shelter_seoul.csv`를 생성하는 스크립트
- `shelter_seoul.csv` : (변환된 데이터셋) 파이썬 기본 인코딩(UTF-8)이 적용된 전처리 파일
- `shelter_ml.py` : 머신러닝(RandomForest, KNN) 데이터 전처리 및 모델 학습, 정확도 평가 스크립트
- `visualize_trees.py` : RandomForest 모델 내부의 의사결정 트리(Decision Tree) 구조를 이미지(`rf_5_trees.png`)로 추출하여 시각화하는 스크립트
- `draw_map.py` : 학습된 예측 모델을 바탕으로 정적 지도 이미지(`blind_spots.png`)를 생성하는 스크립트
- `draw_map_folium.py` : 정제된 데이터를 바탕으로 각 대피소의 동적 커버리지 반경(안전 구역)을 시각화하는 인터랙티브 위성 지도(`shelter_satellite_map.html`) 생성 스크립트

## 🚀 사전 준비 (설치 방법)

이 프로젝트는 파이썬(Python 3) 환경에서 실행되며, 몇 가지 외부 라이브러리를 필요로 합니다.
터미널(또는 명령 프롬프트)을 열고 프로젝트 폴더(`ML2`)로 이동한 뒤 아래 명령어들을 순서대로 입력하세요.

**1. 가상환경 생성 및 활성화 (권장)**
```bash
# 가상환경 생성 (macOS/Linux)
python3 -m venv venv

# 가상환경 활성화 (macOS/Linux)
source venv/bin/activate
```

**2. 필수 패키지 설치**
```bash
pip install pandas scikit-learn numpy matplotlib folium
```

## 💻 실행 방법

### 1. 데이터 인코딩 변환 (최초 1회 실행)
원본 공공데이터(cp949)를 파이썬과 호환성이 좋은 범용적인 UTF-8로 변환합니다.
```bash
python3 convert_encoding.py
```
> **실행 결과**: `shelter_seoul.csv` 파일이 생성됩니다. 이후의 모든 스크립트는 이 파일을 기준으로 동작합니다.

### 2. 머신러닝 모델 학습 및 터미널 테스트
머신러닝 알고리즘을 훈련시키고 특정 좌표의 예측 결과를 텍스트로 보고 싶다면 아래 명령어를 실행합니다.
```bash
python3 shelter_ml.py
```
> **실행 결과**: 정제된 대피소 개수, 모델별 학습 정확도(Accuracy), 임의의 테스트 위치 2곳에 대한 대피소 혜택 확률(%)이 출력됩니다.

### 3. 고해상도 위성 지도 시각화 (권장)
각 대피소의 수용 인원에 비례한 실제 커버리지 반경(반투명 초록색 안전 구역)을 고해상도 위성지도에 직관적으로 그려주는 스크립트입니다.
```bash
python3 draw_map_folium.py
```
> **실행 결과**: 현재 폴더에 `shelter_satellite_map.html` 파일이 생성됩니다. 이 파일을 Chrome, Safari 등의 웹 브라우저로 열면, 자유롭게 확대/축소하며 볼 수 있는 인터랙티브 지도가 나타납니다. (마우스를 올리면 대피소의 수용 인원도 볼 수 있습니다)

### 4. (선택) 정적 지도 이미지 생성
HTML 파일이 아닌 일반 그림 파일(`.png`)로 시각화 결과를 뽑고 싶을 때 사용합니다.
```bash
python3 draw_map.py
```
> **실행 결과**: 설정된 경로에 `blind_spots.png` 파일이 생성됩니다.

## 💡 분석 로직 요약
- **데이터 정제**: `해제일자`가 있는 무효 데이터 및 수용 인원이 없는 데이터 제외
- **동적 커버리지**: 수용 인원 1,000명당 15m씩 커버리지 반경을 동적으로 확장 (최소 50m, 최대 500m 제한)
- **Positive/Negative 라벨링**: 주변 대피소들의 동적 커버리지 안에 속하는 곳을 안전(1), 단 하나의 커버리지에도 속하지 않는 곳을 취약(0)으로 분류하여 학습 수행
